# VLM_RL_ADDS 문서

군중 대피 로봇에서 상위 VLM이 로봇별 임무를 배정하고 하위 정책이 실행하는 구조의 연구 자료를 정리한다.

## 관련 연구 조사

[VLM/LLM 의사결정과 하위 행동 실행: 관련 연구 조사](vlm_rl_related_work_20261015.md)

- 조사일: 2026-10-15.
- 관련 연구 50편: VLM–RL 실행, 계층형 VLA, 다중 로봇 임무 할당, 스킬·기하 제어, 내비게이션, 직접 행동 생성, 보상 설계, 사회적 이동, 자율주행.
- 각 연구의 원문 링크, 상위/하위 역할, RL 사용 위치 및 군중 대피에 적용할 때의 한계.
- 우선 읽을 논문, 제안 구조도, 미션 인터페이스, 실행 가능성·재계획 설계 및 비교 실험.

## 읽는 순서

1. 조사 문서 1장: 서로 다른 VLM/LLM–RL 결합 방식의 구분.
2. 2장과 4장: 하위 RL 실행 및 다중 로봇 역할 할당의 직접 관련 연구.
3. 12장: 우선 읽을 논문.
4. 13장: 프로젝트 적용 제안과 검증 방법.

문헌에서 확인한 구조와 이 프로젝트를 위한 제안을 구분한다. 문서의 설계 제안은 구현 완료 또는 군중 대피 성능 검증을 의미하지 않는다.
